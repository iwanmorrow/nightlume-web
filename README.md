# Nightlume Website

A lightweight website for the Nightlume Minecraft visual client.

The website serves as the project's public hub, allowing users to:

- Register for updates and announcements.
- Follow the development progress.
- Explore basic information about the client.
- Stay informed about upcoming releases.

**Tech stack:** HTML, CSS, JavaScript.

**Status:** Stable.

Private server-side components and environment configuration are not included in the public repository.
